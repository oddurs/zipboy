## Problem

Every string in the app shell is a Swift literal. Translating later would mean hunting through
the code, and plurals ("1 item", "3 items") are built by hand.

## Proposal

Route user-facing text in `Sources/Zipboy` and the messages in `ZipboyKit` through
`String(localized:)` with comments for translators, and ship `Resources/en.lproj/Localizable.strings`
and a `.stringsdict` for plurals, copied into the bundle by `scripts/task build`. Command Line Tools
lack `xcstringstool`, so the tables are the older `.strings` format, generated by a script
from the sources so they never drift.

## Acceptance criteria

- [ ] A script regenerates `Localizable.strings` from the sources, and `scripts/task lint` fails when it is stale
- [ ] Counts use the plural table: "1 item", "2 items", and no hand-built plurals remain
- [ ] Running with `-AppleLanguages '(xx)'` and a test table changes the menu, inspector, and empty state, checked on screen
